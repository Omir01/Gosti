ПРИЛОЖЕНИЕ «БРОНИ И ГОСТИ» ДЛЯ IPHONE — УСТАНОВКА

Что это: приложение открывается с иконки на экране «Домой», работает без интернета.
Таблицы броней вы загружаете в него сами, всё считается прямо в телефоне.
Данные гостей никуда не отправляются: на сайт кладётся только сама программа.

Нужно: компьютер (один раз, для публикации), iPhone с iOS 16.4 или новее, Safari.

------------------------------------------------------------------
ШАГ 1. Опубликовать программу (один раз, на компьютере, бесплатно)
------------------------------------------------------------------
1. Откройте https://github.com и зарегистрируйтесь (бесплатно).
2. Справа вверху нажмите «+» → «New repository».
   Repository name: gosti   ·   Public   ·   нажмите «Create repository».
3. На странице репозитория нажмите ссылку «uploading an existing file».
4. Распакуйте архив и перетащите в окно браузера ВСЕ файлы из папки
   (index.html, app.js, core.js, worker.js, sw.js, manifest.webmanifest,
   xlsx.full.min.js, icon-180.png, icon-192.png, icon-512.png и остальные).
   Внизу нажмите «Commit changes».
5. Откройте «Settings» → слева «Pages».
   Source: «Deploy from a branch». Branch: «main», папка «/ (root)» → «Save».
6. Через 1–2 минуты обновите страницу: вверху появится адрес вида
   https://ВАШ-ЛОГИН.github.io/gosti/
   Этот адрес и есть приложение.

------------------------------------------------------------------
ШАГ 2. Поставить на iPhone
------------------------------------------------------------------
1. Откройте этот адрес в Safari (именно в Safari).
2. Нажмите кнопку «Поделиться» (квадрат со стрелкой) → «На экран "Домой"» → «Добавить».
3. Запускайте приложение с иконки «Гости». Дальше интернет не нужен.

------------------------------------------------------------------
ШАГ 3. Загрузить таблицы броней
------------------------------------------------------------------
1. Сохраните месячные таблицы в Excel в приложение «Файлы» на iPhone.
   Из Google Таблиц: открыть таблицу → «⋯» → «Поделиться и экспортировать»
   → «Отправить копию» / «Сохранить как» → Excel (.xlsx) → «Сохранить в Файлы».
   Из WhatsApp или почты: открыть файл → «Поделиться» → «Сохранить в Файлы».
2. Названия файлов должны быть как сейчас: Бронь_Октябрь_Абая_2026.xlsx
3. В приложении: вкладка «Файлы» → «Выбрать файлы» → отметьте нужные (можно все сразу).
4. Каждый новый месяц загружайте только новые файлы. Файл того же месяца
   и филиала, загруженный ещё раз, заменяет старый (удобно для текущего месяца).

------------------------------------------------------------------
ВАЖНО
------------------------------------------------------------------
• Данные хранятся только в этом телефоне. На другом телефоне нужно загрузить таблицы заново.
• Отметки обзвона: вкладка «Файлы» → «Сохранить копию» время от времени
  (например, отправьте себе в WhatsApp). На новом телефоне — «Восстановить».
• Если удалить иконку с экрана «Домой», данные в телефоне тоже удалятся.
• Обновление программы: загрузите новые файлы в тот же репозиторий на GitHub
  с заменой. Приложение обновится при следующем запуске (иногда со второго раза).
• Адрес приложения можно дать коллегам: у каждого будут свои данные в своём телефоне.
